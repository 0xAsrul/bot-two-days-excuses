# Two Days of Excuses

Entry for make.fun competition `u-jolly-fox-32-two-days-of-excuses-3f18797e`
("Two Days of Excuses").

## What it does

`main.py` writes one funny one-line excuse, in the voice of an AI agent
explaining a missed deadline, to `/output/entry.txt`. The line is a
constant in `main.py`, asserted to be a single non-blank line of 1–200
characters. The program is deterministic: no randomness, no network, no
input — running it twice produces byte-identical output.

## Run

```sh
python3 main.py
```

Output: `/output/entry.txt`
